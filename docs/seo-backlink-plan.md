# Plán legitimního získávání zpětných odkazů (RAJMONDATA)

Backlinky nelze vytvořit pouze úpravou zdrojového kódu. Tento dokument popisuje realistické kroky pro budování autority domény `rajmondata.cz`.

## 1. Firemní profil provozovatele

- Aktualizovat web provozovatele platformy (O nás, kontakt, IČO, reference na RAJMONDATA).
- Propojit logo a odkaz na `https://rajmondata.cz/` z patičky a stránky produktů.

## 2. Partnerské a integrátorské weby

- Partneři (účetní, IT integrátoři, implementace Firestore/hosting) — sekce „Nástroje, které doporučujeme“ s krátkým popisem a odkazem.
- Ecofleet / GPS partneři — zmínka integrace vozového parku (po reálné integraci).

## 3. Katalogy B2B software

- Registrace v katalozích typu SaaS / ERP / stavební software (CZ i SK trh).
- Konzistentní NAP (název, URL, popis) — stejný text jako meta description homepage.

## 4. Oborové články a guest posty

- Články na téma: řízení montážních zakázek, digitalizace řemeslných firem, docházka na tabletu.
- Odkaz na konkrétní landing page (`/rizeni-zakazek`, `/dochazka-zamestnancu`), ne jen homepage.

## 5. Případové studie

- 2–3 anonymizované nebo jmenované case studies (problém → nasazení RAJMONDATA → výsledek).
- Publikace na webu + sdílení partnerům k odkazu.

## 6. PR a média

- Tiskové zprávy při větších verzích (AI modul, vozový park, trial pro firmy).
- Odkaz na `/ai-pro-firmy` nebo `/firemni-portal` podle tématu.

## 7. Zákaznické reference

- Souhlas zákazníka s uvedením loga a odkazu „Provozujeme na RAJMONDATA“.
- Krátký testimonial na landing page + odkaz z webu zákazníka (kde to dává smysl).

## 8. Integrace a partneři

- Dokumentace integrací (e-mail, import poptávek) s odkazem na `/poptavky-a-nabidky`.
- Společné landingy s partnerem (co-branding).

## 9. Firemní sociální profily

- LinkedIn, Facebook stránka firmy — bio s URL, pravidelné posty odkazující na produktové stránky.
- YouTube krátká dema (odkaz v popisu videa).

## 10. Měření

- Google Search Console — sledovat dotazy na brand a produktové stránky.
- Po publikaci obsahu: ruční „Požádat o indexování“ pro nové URL (viz release poznámky).

## Co nedělat

- Link farmy, PBN, automatické komentáře, kupované balíky odkazů.
- Doorway stránky nebo duplicitní obsah pro různé domény.
